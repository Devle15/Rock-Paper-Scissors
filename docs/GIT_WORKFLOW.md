Muc tieu: moi thanh vien co commit ro rang va co dong gop that.

## Quy trinh de xuat
- Tao repo moi tren GitHub.
- Moi nguoi lam viec tren nhanh rieng: feature/<ten>-<module>.
- Mo Pull Request, leader review va merge.
- Moi nguoi toi thieu 5-10 commit co y nghia, trai deu trong 5-7 ngay.
